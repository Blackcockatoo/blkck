# Japanese & Hindi (blkck2.com/ja/, blkck2.com/hi/)

Everything is static HTML built by `node scripts/build-worlds.mjs`, same as the English world pages.

| What | Where |
|---|---|
| Translations | `data/i18n/ja.js`, `data/i18n/hi.js` — UI strings, the 16 studio sections, proof-strip facts, world one-liners, track labels, 87 artwork descriptions, 12 store blurbs |
| Pages | `/ja/`, `/hi/` (home), `/<lang>/store/`, `/<lang>/<world>/` for all 15 worlds |
| Share cards | `share/ja/*.jpg`, `share/hi/*.jpg` — `python3 scripts/make-share-cards.py` |
| SEO | `<html lang>`, `og:locale`, `hreflang` en/ja/hi/x-default on every pair (English pages too), localized sitemap with `xhtml:link` alternates |
| Switcher | A small globe button in the top-right corner (top bar on generated pages, masthead on the portal, pinned top-right on hand-written pages) opens a list: English, 日本語 (Japanese), हिन्दी (Hindi), current one ticked. Trilingual label "Language / 言語 / भाषा"; `<details>` so it works without JS, `bss-components.js` adds outside-click/Escape/arrow keys. Footers carry a quiet text row of the same links. Browsers set to ja/hi get a one-time dismissible suggestion (never an auto-redirect). |
| Fonts | Only on ja/hi pages: Noto Serif JP + Noto Sans JP, Tiro Devanagari Hindi + Noto Sans Devanagari (Google Fonts, unicode-range slices, `display=swap`). English pages load nothing new. |

## Editing copy
Change a string in `data/i18n/<lang>.js`, then run `node scripts/build-worlds.mjs && node scripts/check-worlds.mjs`.
A missing or `null` entry falls back to English and is marked `lang="en"` so screen readers and fonts switch correctly.

## Left in English on purpose
- Brand and project names (B$S, Blue $nake Studio, The Moss Man, Old Vic State, Black Wing Crew, Neon Venom, Meta-Pet, Moss 60, STOMPS, Auralia…)
- Song titles, moods and artwork titles; text baked into images and posters
- Old Vic State manifesto line ("One wing remembers fire…") and its core line
- Kṛṣṇapakṣi tagline ("The black bird wears the prayer.") — devotional voice, wants a native Hindi speaker
- The hand-written English pages themselves (store.html, black-wing-crew.html, stomps.html …): their localized twins are generated from the same data instead

See `skipped` in each translation file for the running list.
